# UI copy

- Copy explains what is happening and why someone should care. Define vague words. Show the benefit at each step.
- Use plain words a client would use. No AI-sounding phrases or internal jargon.
- Use short, simple labels ("Requests", "Changes"). Keep notice text simple.
- Remove lists and details that repeat what is already shown.
- No placeholder names or editorial notes in shipped content.
- Use personal, action-oriented CTAs ("Talk to <name>").
- Write READMEs and docs in a plain, direct voice.
