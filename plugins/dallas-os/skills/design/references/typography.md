# Typography

- Use the design system's font-size tokens, not a custom text scale.
- Never center text. Left-align body and UI text.
- Keep the key message large. Never let a headline or key text get tiny or crammed.
- Default to smaller, restrained sizes for card titles, form labels, and secondary UI. If something feels too large, drop the size.
- Keep line lengths short and break up walls of text.
- Check button line-height and vertical alignment with custom fonts, so labels sit centered.
- Tune a display font's line-height so it centers optically in buttons, chips, and rows.
- Use a monospace font for badges, short action words, and system labels. Keep badges small and all caps.
- Use normal weight (400) for button labels, not semibold.
- Headings use the title text color, not the muted color.
- Label form fields in a dark enough color. Keep helper text tight to its input.
- Load custom fonts through the framework's font loader. Keep an alternate font commented out instead of shipping a font picker.
- Keep helper and body text small so notices and card copy do not dominate the layout. (The text in the columns notice was too large.)
- Set line-height tight so text centers evenly in buttons and labels. (Tall line-height pushed text off center.)
- Let site owners pick fonts in Studio, and build the type scale from the brand. (Owners need to control their own type. This is for Studio, so it differs from the fixed-font rule for developer code.)
- Keep font weight when converting text to vector. (Converting bold text to vector made it thinner.)
- Set body text to at least 16px, font weight 400, and line-height 1.6. (Body text must be easy to read at length.)
- Set monospace labels and tags to font weight 500 (medium). (Medium weight keeps small mono tags readable next to sans text.)
- Match the user manual's text styles, line height, and heading weight to the brand kit. (The manual's line height and heading weight did not match the kit.)
- Show headlines as thicker placeholder lines and body copy as thinner lines in graphic text. (Line weight shows the difference between headline and body, like real type.)
