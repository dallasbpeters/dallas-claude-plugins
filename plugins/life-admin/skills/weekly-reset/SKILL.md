# Weekly reset

A 15-minute sweep that leaves the person knowing what matters this week. Use whatever is connected; skip a step, and say so in one line, when its source isn't available.

1. **Email.** Run a light inbox-zero pass: archive the obvious, list what needs a reply, draft the easy replies. Never send.
2. **Calendar.** List the coming 7 days: appointments, deadlines, anything that needs prep (a document, a gift, a payment).
3. **Tasks.** Read the task list (the notes folder's `60 Tasks.md`, or the connected task app). Mark what's clearly done, flag anything overdue, and move stale items to Someday after asking.
4. **Notes inbox.** If a notes folder is connected, file the `00 Inbox` notes (second-brain skill).
5. **Files.** If Downloads or Desktop is connected, run a file-cleanup scan and report the summary only. Apply nothing without a yes.
6. **The plan.** Finish with:
   - **This week's top 3**
   - **Replies owed** (who, about what)
   - **Dates** (what's coming, what needs prep)
   - **Waiting on** (who owes them something)
   Keep it under a screen. If a notes folder is connected, save it to `50 Journal/` as `YYYY-MM-DD Weekly.md`.

Offer once to make it a scheduled task (for example Sunday evenings). Scheduled runs follow the same rules: drafts only, nothing sent or deleted.
